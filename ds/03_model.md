# 3. 모델: 지도(분류/회귀) vs 비지도(군집/연관) + 알고리즘(현대 데이터 마이닝)

해결하려는 주제와 데이터의 상태, 제약 조건에 알맞은 알고리즘을 선택하여 모델을 구축하는 단계이다.

모델을 결정하는 기준은 여러 가지가 있고, 기준들을 동시에 고려하여 모델을 선택하게 된다.

---

모델을 결정하는 기준
1. 데이터의 형태: 정형 / 반정형 / 비정형
2. 학습 방식: 정답이 데이터에 포함되어 있는가?
3. 태스크: 정답이 분류인가? 회귀인가?
4. 구조/설명성

데이터의 형태가 모델의 종류를 결정하는데 큰 영향을 끼친다.

---

데이터의 형태에 따른 모델
1. 정형 데이터 분석 모델
- Random Forest
- Gradient Boosting(XGBoost / LightGBM / CatBoost)
- 선형 회귀
- 로지스틱 회귀
- 서포트 벡터 머신
2. 이미지 데이터 분석 모델
- CNN
- ResNet
- YOLO
- Vision Transformer
3. 텍스트 및 시계열 데이터 분석 모델
- RNN / LSTM
- Transformer
- LLM
4. 데이터 생성 모델
- GAN
- Diffusion Model

---

학습 방식에 따른 모델

1. 지도 학습
2. 비지도 학습
3. 강화 학습

---

태스크(결과 형태)에 따른 모델

1. 이진 분류
2. 객체 검출
3. 군집화
