# 1. 엔지니어링: ETL, 데이터 수집, DB 설계

데이터 분석을 진행하기 위해서는 분석 대상 데이터를 수집해야 하고 그 데이터를 담는 데이터베이스를 설계해야 한다.

---

구조와 형태에 따라 데이터를 분류한다면 3가지로 분류할 수 있다.

1. 정형 데이터: 미리 정해진 스키마에 맞춰 표 형태로 엄격하게 구조화된 데이터
- 특징: 데이터의 길이, 형식, 순서가 고정되어 있기에 분석하기 용이하다.
- 예시: 관계형 데이터베이스(RDB), 엑셀 스프레드시트

2. 반정형 데이터: 정형 데이터처럼 표 형태로 저장되지는 않지만 데이터 내부에 자체적인 구조 정보를 포함한 데이터
- 특징: 정형 데이터보다 형태가 유연하며, 데이터 추가나 구조 변경이 자유롭다.
- 예시: XML, JSON, HTML

3. 비정형 데이터: 스키마가 없어 형태가 고정되어 있지 않은 데이터
- 특징: 미리 정해진 구조와 형태가 없기에 분석과 처리가 복잡하다.
- 예시: 동영상, 오디오, 이미지, 음성 파일

---

데이터베이스의 종류

1. 관계형 데이터베이스
- 적합 데이터: 정형 데이터
- 종류: Oracle, MySQL, PostgreSQL
2. NoSQL 데이터베이스
- 적합 데이터: 반정형 데이터
- 종류: MongoDB, Redis
3. 벡터 데이터베이스
- 적합 데이터: 비정형 데이터
4. 그래프 데이터베이스
5. 시계열 데이터베이스
