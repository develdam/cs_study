# 3. 모델: 지도(분류/회귀) vs 비지도(군집/연관) + 알고리즘(현대 데이터 마이닝)

해결하려는 주제와 데이터의 상태, 제약 조건에 알맞은 알고리즘을 선택하여 모델을 구축하는 단계이다.

---

모델을 결정하는 기준은 여러 가지가 있고, 기준들을 동시에 고려하여 모델을 선택하게 된다. 
1. 태스크: 어떤 결과 형태를 원하는가?
- 이진 분류: (ex. 성별 예측)
- 다중 분류: (ex. 연령대 예측)
- 회귀: (ex. 아파트 가격 예측)
- 객체 검출: (ex. CCTV 화면에서 마스크를 쓰지 않은 사람)
2. 데이터의 형태
- 정형(+반정형) 데이터: 관계형 테이블, 엑셀 및 CSV 파일
- 비정형 데이터: 이미지, 동영상, 오디오
3. 학습 방식: 정답이 데이터에 포함되어 있는가?
- 지도 학습: 정답 레이블이 있을 때
- 비지도 학습: 정답 레이블이 없을 때

---

모델의 종류와 사용 예시

1. Random Forest(랜덤 포레스트)
- 태스크: 이진 분류, 다중 분류, 회귀
- 데이터의 형태: 정형 데이터
- 학습 방식: 지도 학습
- 실무 예시: 은행 고객의 데이터(ex. 나이, 연소득, 연체 이력)를 활용하여 신용카드 대출 연체 위험도 예측

2. CNN(Convolutional Neural Network)
- 태스크: 이진 분류, 다중 분류
- 데이터의 형태: 이미지 데이터(비정형)
- 학습 방식: 지도 학습
- 실무 예시: 의료 X-ray 영상(이미지)을 통해 폐렴 진단

3. YOLO(You Only Look Once)
- 태스크: 객체 검출
- 데이터의 형태: 이미지 데이터, 실시간 영상 데이터
- 학습 방식: 지도 학습
- 실무 예시: 자율주행 차량의 실시간 장애물 및 보행자 감지
