# 5. 평가: F1, ROC, AUC, RMSE(데이터+모델의 성적표)

학습이 끝난 모델이 실제 환경에서 얼마나 잘 작동할지 객관적인 지표로 검증하는 단계이다. 모델의 종류, 즉 출력되는 결과의 형태(범주형, 연속형)에 따라 다른 평가 지표를 사용한다.

---

평가 지표의 종류
1. 분류 모델 평가 지표: 정답이 '예/아니오' 또는 'A/B/C'처럼 범주형인 모델을 평가할 때 사용한다.
- Confusion Matrix(혼동 행렬)
- Accuracy(정확도): 전체 데이터 중 맞게 예측한 비율
- Precision(정밀도): 모델이 양성으로 예측한 것 중, 실제 양성인 데이터 비율
- Recall(재현율/민감도): 실제 양성 데이터 중, 모델이 양성으로 올바르게 맞춘 비율
- F1 Score: 정밀도와 재현율의 조화평균
- ROC-AUC

2. 회귀 모델 평가 지표: 정답이 '집값', '매출'처럼 연속된 숫자 형태인 모델을 평가할 때 사용하는 지표로 값이 낮을수록 우수한 모델이다.
- MAE: 실제값과 예측값의 차이(오차)를 절대값으로 변환해 평균을 낸 값
- MSE: 실제값과 예측값의 오차를 제곱하여 평균을 낸 값으로 오차를 제곱하기 때문에 큰 오차(이상치)에 대해 매우 민감하게 반응한다.
- RMSE: MSE 값에 루트를 씌운 지표이다. 오차에 대해 민감하면서 루트를 통해 타겟 변수와 단위를 다시 일치시킨 지표이기 때문에 가장 많이 활용된다.
- **R^2(결정계수): 데이터의 전체 분산 중 모델이 얼마나 데이터를 잘 설명(예측)하는지 비율로 나타낸 지표**
3. 군집화 모델 평가 지표
- 실루엣 계수: 정답(레이블)이 없는 상태에서 군집 내부 데이터끼리는 얼마나 잘 뭉쳐 있는지와 서로 다른 군집끼리는 얼마나 멀리 떨어져 있는지를 동시에 측정하는 지표
