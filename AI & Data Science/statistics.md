AI와 Data Science의 데이터 모델의 근간은 통계학이다. 과거에는 대규모 데이터의 부재와 컴퓨터 성능의 한계로 구현에 제약이 많았다. 현대에 이르러 대규모 데이터와 발전된 컴퓨터의 성능이 전통적인 통계학과 합쳐져 현대 머신러닝 모델이 되었고, 뛰어난 성과를 창출하고 있다.

예를 들어 과거 통계학이 5개의 특성을 가진 100개의 소규모 데이터로만 단순한 Linear Regression(통계학적 기법)만을 분석했다면, 현대 머신러닝 모델은 30개 이상의 특성을 가진 10,000개의 대규모 데이터를 통계학적 기법과 컴퓨터 연산 능력을 활용하여 변수 간의 훨씬 복잡하고 비선형적인 관계까지 정밀하게 분석할 수 있게 된 것이다.

**통계학을 몰라도 머신러닝 모델 코드를 돌려 결과를 얻을 수는 있다. 하지만 통계학적 이해가 없다면 그 모델이 내놓은 결과가 무엇을 의미하는지 해석하는데 한계가 있다.**

## 모델의 통계학적 기반
데이터 분석 모델과 AI 모델의 구분은 모델의 주 사용 용도에 따라 단순 구분한 것으로 절대적인 기준이 아니다. 볼드 처리된 부분은 통계학과 관련된 용어이며, 이 또한 절대적인 기준은 아니다.
1. 지도 학습 & 데이터 분석 모델
- Linear Regression: 모델이 예측한 값과 실제 정답의 차이인 잔차를 제곱하여 다 더한 값인 **SSE**가 최소가 되는 직선의 기울기와 절편을 수학적으로 구해낸다. 이후 **p-value**를 보고 어떤 변수가 진짜 중요한지 판단한다.
- Logistic Regression: 단순 선형 수식의 결과를 0과 1 사이의 확률값으로 바꾸기 위해 **시그모이드 함수**를 씌우고, 데이터가 나올 확률인 **우도**를 가장 크게 만드는 가중치를 **MLE**로 찾아낸다.
- XGBoost, LightGBM: **결정 트리**를 쪼갤 때 어느 기준으로 나눠야 데이터의 불확실성(**엔트로피/지니계수**)이 줄어들지 계산한다.
2. 비지도 학습 & 데이터 분석 모델
- PCA: 데이터 변수들 간의 통계적 상관관계를 나타내는 **공분산 행렬**을 만든다. 이후 **데이터의 분산, 즉 정보량**이 가장 크게 퍼져있는 축인 **고유벡터**를 선형대수/통계 기법으로 찾아내어 차원을 축소한다.
- K-Means Clustering: 데이터 공간상에서 좌표 간의 **통계적 거리**를 계산한다. 각 그룹에 속한 데이터들의 **통계적 평균점**을 반복적으로 계산해 중심을 이동시키며 군집을 형성한다.
3. 지도 학습 & AI 모델
- CNN / ResNET: 이미지의 픽셀 데이터가 신경망을 통과할 때, 값이 튀지 않도록 **평균과 분산**으로 **정규화**한다. 마지막 레이어에서는 Softmax 함수를 적용하여 **통계적 확률 분포**로 변환한 뒤, 정답과의 차이를 크로스 엔트로피(**손실함수**)로 계산한다.
- YOLO / ViT: 화면의 특정 영역에 물체가 존재할 **조건부 확률**을 계산하고, Bounding Box 좌표의 오차를 **연속형 통계 손실**(MSE/GloU Loss)로 계산하여 **경사하강법**으로 맞춘다.
4. 비지도 학습 & AI 모델
- Transformer / LLM(GPT, Gemini, Claude): 앞의 단어들이 주어졌을 때, 다음에 올 단어의 **조건부 확률**을 수천억 개 가중치 파라미터(발전된 컴퓨터 연산 능력)로 계산하여 가장 확률이 높은 단어를 통계적으로 추출한다.
- Diffusion: 노이즈가 없는 이미지에 **가우시안 노이즈**를 단계별로 섞어 완벽한 노이즈 상태로 만든 뒤, 역방향으로 확률 미분 방정식을 풀어 노이즈를 조금씩 제거해 나가면서 새로운 이미지를 정밀하게 복원하고 생성한다.
