# Data Science(데이터 과학/분석)
데이터 과학은 위키피디아의 정의에 따르면 "정형, 비정형 형태를 포함한 다양한 데이터로부터 지식과 인사이트를 추출하는 과정에서 과학적 방법론, 프로세스, 알고리즘, 시스템을 동원하는 융합 분야"이다.

## 데이터 분석의 과정
데이터 분석의 과정은 크게 6가지 과정으로 이루어진다.

1. 엔지니어링: ETL, 데이터 수집, DB 설계
- 데이터 분석을 진행하기 위해서는 분석 대상 데이터를 수집해야 하고 그 데이터를 담는 데이터베이스를 설계해야 한다.
2. 데이터: EDA, 품질 평가, 상관 분석, PCA(전통적 통계분석)
- 수집한 데이터를 분석하기 전에 가져온 데이터의 특징을 파악하고, 모델에 데이터를 투입할 수 있도록 데이터를 정제 및 차원 축소하는 통계적 접근 단계이다.
3. 모델: 지도(분류/회귀) vs 비지도(군집/연관) + 알고리즘(현대 데이터 마이닝)
- 해결하려는 주제와 데이터의 상태, 제약 조건에 알맞은 알고리즘을 선택하여 모델을 구축하는 단계이다.
4. 최적화: 파라미터 수집, 손실 함수, 경사하강법(수학적 원리)
- 모델이 데이터의 패턴을 가장 정확하게 맞출 수 있도록 내부 가중치를 수학적으로 조정하는 단계이다.
5. 평가: F1, ROC, AUC, RMSE(데이터+모델의 성적표)
- 학습이 끝난 모델이 실제 환경에서 얼마나 잘 작동할지 객관적인 지표로 검증하는 단계이다. 모델의 종류, 즉 출력되는 결과의 형태(범주형, 연속형)에 따라 다른 평가 지표를 사용한다.
6. 응용과 비즈니스 문제 해결
- 학습 및 평가가 완료된 모델을 실제 서비스 환경에 탑재하고 분석 결과를 시각화하여 실질적인 비즈니스 문제 해결을 위한 의사결정을 지원하는 단계이다.

데이터 분석의 목표는 비즈니스 문제 해결(ex. 수익 극대화, 원가 감소)이다.

## 데이터사이언스학과와 기존 학과의 차이점
데이터사이언스학과는 기존 학문을 융합한 학과이기에 학과를 엄밀하게 정의하기에 무리가 있다. 커리큘럼 상 분명한 차이는 있지만 겹쳐지는 부분도 많다.

1. 통계학과 vs 데이터사이언스학과: 정형 데이터 vs 비정형 데이터
2. 인공지능공학과 vs 데이터사이언스학과: 인공지능 모델과 알고리즘 vs 데이터에서 가치 추출

# Artificial Intelligence(인공지능)
인공지능은 위키피디아의 정의에 따르면 인간의 학습능력, 추론능력, 지각능력을 인공적으로 구현하려는 컴퓨터 과학의 세부 분야 중 하나이다.

## 파이썬 머신러닝/딥러닝 라이브러리
1. Scikit-learn(사이킷런): 분류, 회귀, 군집화 등 전통적인 머신러닝 알고리즘을 제공하는 파이썬 라이브러리
2. TensorFlow(텐서플로우): 구글이 개발한 대규모 딥러닝 및 신경망 연산용 라이브러리
3. PyTorch(파이토치): 페이스북이 개발하여 직관적인 코드와 빠른 연산으로 널리 쓰이는 딥러닝 라이브러리
